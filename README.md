# HavenFind

Map-first real estate portal with spatial search, rich filters, a mortgage calculator and viewing bookings.

## Planned features
- Map + list view: listings from PostGIS bounding-box query for the current viewport, clustered pins, hover/click syncing with cards.
- Filters: price range, bedrooms, bathrooms, square footage, property type, amenities; URL-synced state; sort.
- Listing detail page with local image gallery, mortgage estimator (price, deposit, rate, term), and saved/bookmarked homes.

### Phase 2
- Agent viewing booking calendar
- Draw-a-boundary polygon search
- Compare listings
- Email alert signups (stored only)

## Stack
Next.js (App Router), TypeScript strict, Tailwind CSS, Leaflet + react-leaflet with OpenStreetMap tiles, leaflet.markercluster, Drizzle with Neon Postgres (PostGIS extension), Netlify
